# Voting

This folder contains an implementation of the **Voting Ensemble** method using Python and Scikit-learn.

## 📌 Overview

Voting is an ensemble learning technique that combines the predictions of multiple machine learning models to make a final prediction.

The final prediction is based on the combined decisions of the individual models.

Voting can be used for both:

- **Classification**
- **Regression**

## 🧠 Concepts Covered

- Ensemble Learning
- Voting Ensemble
- Combining Multiple Models
- Voting Classifier
- Voting Regressor
- Model Training and Prediction
- Model Evaluation

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Jupyter Notebook

## 📁 Files

| File | Description |
|---|---|
| `voting_classifier.ipynb` | Voting Ensemble classification implementation |
| `voting_regressor.ipynb` | Voting Ensemble regression implementation |

## 🎯 Learning Objective

The purpose of these implementations is to understand how **Voting Ensembles** combine multiple machine learning models to produce a final prediction for classification and regression problems.
