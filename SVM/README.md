# Support Vector Machine (SVM)

This folder contains implementations of **Support Vector Machine (SVM)** for classification and regression using Python and Scikit-learn.

## 📌 Overview

Support Vector Machine is a supervised machine learning algorithm that finds an optimal decision boundary to separate data points into different classes.

SVM can be used for both:

- **Classification**
- **Regression**

## 🧠 Concepts Covered

- Support Vector Machines
- Maximum Margin Classification
- Support Vectors
- Decision Boundaries
- SVC (Support Vector Classification)
- SVR (Support Vector Regression)
- Model Training and Prediction
- Model Evaluation

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Jupyter Notebook

## 📁 Files

| File | Description |
|---|---|
| `SVC_implementation.ipynb` | Support Vector Classification implementation |
| `SVR_implementation.ipynb` | Support Vector Regression implementation |

## 🎯 Learning Objective

The purpose of these implementations is to understand how **Support Vector Machines** can be applied to both classification and regression problems using different decision boundaries and support vectors.
