# Lasso Regression

This folder contains an implementation of **Lasso Regression** using Python and Scikit-learn.

## 📌 Overview

Lasso Regression is a regularized linear regression technique that adds an **L1 penalty** to the model.

It helps reduce overfitting and can perform feature selection by shrinking some coefficients to zero.

## 🧠 Concepts Covered

- Linear Regression
- L1 Regularization
- Alpha (regularization strength)
- Feature selection
- Model training and prediction
- Model evaluation

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Jupyter Notebook

## 📁 Files

| File | Description |
|---|---|
| `lasso_regression.ipynb` | Lasso Regression implementation |

## 🎯 Learning Objective

The purpose of this implementation is to understand how **L1 regularization** can be used with linear regression to control model complexity and reduce overfitting.
