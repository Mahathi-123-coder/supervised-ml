# Gradient Boosting

This folder contains implementations of **Gradient Boosting** for classification and regression using Python and Scikit-learn.

## 📌 Overview

Gradient Boosting is an ensemble learning technique that builds multiple weak learners sequentially, where each new model focuses on reducing the errors made by the previous models.

It can be used for both:

- **Classification**
- **Regression**

## 🧠 Concepts Covered

- Ensemble Learning
- Boosting
- Gradient Boosting Classification
- Gradient Boosting Regression
- Sequential Model Training
- Model Prediction
- Model Evaluation

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Jupyter Notebook

## 📁 Files

| File | Description |
|---|---|
| `Gradient_Boosting_Classifier.ipynb` | Gradient Boosting classification implementation |
| `Gradient_Boosting_Regressor.ipynb` | Gradient Boosting regression implementation |

## 🎯 Learning Objective

The purpose of these implementations is to understand how **Gradient Boosting** combines multiple weak learners sequentially to build a stronger predictive model for both classification and regression tasks.
