# Random Forest

This folder contains an implementation of the **Random Forest** algorithm using Python and Scikit-learn.

## 📌 Overview

Random Forest is an ensemble learning algorithm that combines multiple Decision Trees to produce a more accurate and robust model.

It can be used for both **classification** and **regression** problems.

## 🧠 Concepts Covered

- Ensemble Learning
- Decision Trees
- Bagging
- Random Forest
- Feature Randomness
- Model Training and Prediction
- Model Evaluation

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Jupyter Notebook

## 📁 Files

| File | Description |
|---|---|
| `random_forest.ipynb` | Random Forest implementation |

## 🎯 Learning Objective

The purpose of this implementation is to understand how multiple Decision Trees can be combined to create a stronger and more stable machine learning model.
