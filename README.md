# 🤖 Supervised Machine Learning Implementations

A collection of supervised machine learning algorithm implementations using Python and Scikit-learn. This repository contains hands-on implementations covering regression, classification, and ensemble learning techniques.

## 📚 Algorithms Implemented

| Algorithm | Type | Folder |
|---|---|---|
| Linear Regression | Regression | [linear-regression](./linear-regression) |
| Logistic Regression | Classification | [logistic-regression](./logistic-regression) |
| Lasso Regression | Regression | [lasso-regression](./lasso-regression) |
| k-Nearest Neighbors (kNN) | Classification | [kNN](./kNN) |
| Naive Bayes | Classification | [naive-bayes](./naive-bayes) |
| Decision Tree | Classification & Regression | [decision-tree](./decision-tree) |
| Random Forest | Ensemble | [random-forest](./random-forest) |
| Gradient Boosting | Ensemble | [gradient-boosting](./gradient-boosting) |
| AdaBoost | Ensemble | [Adaboost](./Adaboost) |
| Support Vector Machine (SVM) | Classification & Regression | [SVM](./SVM) |
| XGBoost | Classification | [xgboost](./xgboost) |
| Voting | Ensemble | [voting](./voting) |
| Stacking | Ensemble | [stacking](./stacking) |

## 🧠 Topics Covered

This repository covers several important concepts in supervised machine learning:

- Regression
- Classification
- Regularization
- Distance-based learning
- Probabilistic classification
- Decision Trees
- Ensemble Learning
- Bagging
- Boosting
- Support Vector Machines
- Model Evaluation
- Model Training and Prediction
- Hyperparameter Tuning

## 📊 Learning Progression

The implementations progress from fundamental supervised learning algorithms to more advanced ensemble techniques:

**Regression → Classification → Decision Trees → Ensemble Learning → Boosting → Advanced Ensemble Methods**
