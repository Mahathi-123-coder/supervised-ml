# Stacking

This folder contains an implementation of the **Stacking Ensemble** method using Python and Scikit-learn.

## 📌 Overview

Stacking is an ensemble learning technique that combines the predictions of multiple machine learning models and uses another model, called a **meta-model**, to make the final prediction.

Stacking can be used for both:

- **Classification**
- **Regression**

## 🧠 Concepts Covered

- Ensemble Learning
- Stacking
- Base Learners
- Meta-Model
- Combining Multiple Models
- Stacking Classifier
- Stacking Regressor
- Model Training and Prediction
- Model Evaluation

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Jupyter Notebook

## 📁 Files

| File | Description |
|---|---|
| `stacking_classifier.ipynb` | Stacking Ensemble classification implementation |
| `stacking_regressor.ipynb` | Stacking Ensemble regression implementation |

## 🎯 Learning Objective

The purpose of these implementations is to understand how **Stacking Ensembles** combine multiple base models and a meta-model to improve predictions for classification and regression problems.
